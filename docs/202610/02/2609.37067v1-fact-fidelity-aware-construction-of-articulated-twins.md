## 摘要
视觉上看似合理的铰接资产在接触交互中仍可能失效，或表现出不准确的运动。我们提出 FACT（保真度感知的铰接孪生构建），一种智能体框架，以渐进方式构建铰接孪生，从而提升几何、接触和动力学保真度。该智能体在共享的可编辑表示上驱动“证据—诊断—修正”循环，利用定量反馈选择测量和模型编辑，同时由数值工具执行并验证更新。它通过特征规划、定向测量和诊断细化，从图像中重建可编辑的铰接几何。在此参考基础上，它通过任务感知的局部重分区修复碰撞代理，然后再进行保真度约束的压缩。最后，它从被动响应视频中构建响应模型，利用仿真残差指导模型修正和受约束的物理参数拟合。实验表明，FACT 在几何重建上优于基线，能够以更简单的碰撞代理实现更可靠的交互，并且比直接参数推断更好地复现留出的物理响应。

## Abstract
Visually plausible articulated assets may still fail during contact interactions or exhibit inaccurate motion. We present FACT (Fidelity-Aware Construction of Articulated Twins), an agentic framework that progressively constructs articulated twins to improve geometry, contact, and dynamic fidelity. The agent drives an evidence--diagnosis--revision loop on a shared editable representation, selecting measurements and model edits using quantitative feedback, while numerical tools execute and validate the updates. It reconstructs editable articulated geometry from images through feature planning, targeted measurements, and diagnostic refinement. On this reference, it repairs collision proxies through task-aware local repartitioning before fidelity-constrained compression. Finally, it constructs response models from passive-response videos, using simulation residuals to guide model revision and constrained physical parameter fitting. Experiments show that FACT improves geometric reconstruction over baselines, enables more reliable interaction with simpler collision proxies, and better reproduces held-out physical responses than direct parameter inference.

## 2. 方法论

### 2.1 总体框架：证据—诊断—修正循环

- 铰接孪生表示为 **A = (G, K, C, θ)**：部件几何 G、运动学图 K、碰撞代理 C、物理参数 θ。
- 三个阶段串行：特征规划/测量/细化与关节化建立 **(G, K)** → 任务感知接触修复 **C** → 视频驱动动力学标定 **θ**。
- 每个阶段都遵循 **evidence–diagnosis–revision** 循环：**智能体**负责语义理解层面的测量选择与模型编辑决策，**数值工具**负责执行操作并返回定量反馈；共享的部件身份与 body frame 保证跨阶段对应关系。

### 2.2 几何保真度：特征规划—测量—细化

- **特征规划**：智能体检查整物体视图与孤立部件视图，识别逻辑部件及其结构需求，产出特征计划（特征类型、关系、待测参数、与源区域的链接）。部件可由拉伸、扫掠、壳体、减材特征组合，词表外形状允许自定义构造；规划明确"要表示什么、要测量什么"，但不定数值。
- **特征条件测量**：对每个计划参数，智能体选择源区域、坐标系与测量流程，几何工具计算数值。投影轮廓与轴向范围约束拉伸的剖面与深度；截面中心与接触区域约束手柄路径与端点；测量轮廓被简化为可编辑的剖面控制量；依赖参数通过对称、重复、接触关系推导。所有测量/推导记录保留以便后续修正。
- **可执行程序**：计划被实现为带几何参数 φ 的可执行程序 **P(φ)**，由可编辑特征生成重建部件网格 **Ĝ**，而非复制源三角面。
- **诊断细化**：用双向表面距离、匹配视角轮廓、并排渲染对比 Ĝ 与 M；部件级诊断借助源对应关系定位错误，必要时用定向视图/截面解决遮挡结构。错误被追溯到具体建模决策：**特征表示不足 → 重规划；尺寸/位置错误 → 重测量；实现错误 → 程序修正**。只有同时通过自动几何验证与智能体目视检查才被接受。
- **功能补全与关节化**：单独一轮补充最小功能结构（空腔、支撑、安装位），由类别知识引导不可见结构、由测量包络与功能间隙约束尺寸。一起运动的部件归为刚体；每个关节在 K 中指定父子 body、类型、轴、原点、运动限位。采样位姿（含行程端点）用于暴露干涉并触发几何或关节放置修正。

### 2.3 接触保真度：任务感知碰撞细化

- **表示与初始化**：每个刚体 b 的碰撞代理为凸包并集 **C_b = ∪_{h=1}^{H_b} C_{b,h}**，C 为全体 hull 集合。分解区域作为 CoACD 的输入，允许在 body 内重分区但保留全部源几何；G 与 K 固定。默认区域分解 **C₀** 初始化代理，并设定 hull 预算 **H_max = H(C₀)**。
- **任务感知诊断**：智能体识别可能交互并选择接触区域、可达空间、运动间隙进行评估。**任务自由空间**定义为各姿态下参考 body 几何并集之外的空间（与候选代理无关）。评估指标包括：逐 body 体积重叠、缺失/多余体积、任务区域占用、以及在"参考确认无碰撞"位姿上的伪体间碰撞。运动检查覆盖完整行程（含端点），失败附近加密采样；诊断给出责任 hull 对与源区域。
- **诊断式分区精修**：智能体选择局部编辑——重分区/拆分区域、调整区域分解参数、合并兼容区域或 hull。论文举例：把手柄拆成侧支撑与桥接部分
