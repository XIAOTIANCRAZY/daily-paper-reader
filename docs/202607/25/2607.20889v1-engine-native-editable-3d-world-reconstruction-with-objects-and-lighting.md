## 摘要
可编辑3D场景创建需要能够被检查、移动并导入标准引擎的物体实例与光源，然而现有的单图像方法大多局限于房间尺度几何、烘焙/全局光照或文本驱动生成。我们提出Lumera（光感知统一引擎原生重建与装配），这是一个面向从单图像进行引擎原生、光感知3D场景解析的基准与参考流水线。Lumera-2K基于2,513个UE5项目构建，提供373万个组件、6300万个物体实例、10.26万个引擎原生参数化光源以及9.51万个相机视角。在此数据上，Lumera-Box与Lumera-Light适配VLM以解析物体框与参数化光源元组（x,y,z,r,g,b,I），并通过逐物体网格重建、HDR环境估计以及受限智能体优化循环进行装配。在与DetAny3D、SpatialLM、N3D-VLM及WildDet3D的无干扰框基准对比中，Lumera-Box在整体检测、几何、语义与布局得分上最强（合并mAP 0.1141，IoU-B 0.2472，F-score 0.2762），而WildDet3D在锚点召回率上仍更强。对于光源，Lumera-Light几乎恢复了所有非空场景（召回率0.998），但在单个光源定位上仍有限（0.5米处F1为0.209）；匹配光源的中位位置误差为0.261米，中位ΔE2000为4.59，强度皮尔逊r=0.628。这些结果确立了参数化光源作为可测量可编辑场景目标，并揭示了关系结构、光源召回率/强度及跨引擎泛化方面的剩余瓶颈。

## Abstract
Editable 3D scene creation requires object instances and lights that can be inspected, moved, and imported into standard engines, yet existing single-image methods largely stop at room-scale geometry, baked/global illumination, or text-driven generation. We introduce Lumera (Light-aware Unified Engine-native Reconstruction and Assembly), a benchmark and reference pipeline for engine-native, light-aware 3D scene parsing from a single image. Lumera-2K is built from 2,513 UE5 projects and provides 3.73M components, 63M object instances, 102.6K engine-native parametric lights, and 95.1K camera views. On this data, Lumera-Box and Lumera-Light adapt VLM to parse object boxes and parametric light tuples (x,y,z,r,g,b,I), which are assembled with per-object mesh reconstruction, HDR environment estimation, and a bounded agentic refinement loop. In a sanitized box benchmark against DetAny3D, SpatialLM, N3D-VLM, and WildDet3D, Lumera-Box obtains the strongest overall detection, geometry, semantic, and layout scores (merged mAP 0.1141, IoU-B 0.2472, F-score 0.2762), while WildDet3D remains stronger on anchor recall. For lights, Lumera-Light recovers almost all non-empty scenes (recall 0.998) but remains limited at individual-light localization (F1 0.209 at 0.5 m); matched lights have median position error 0.261 m, median ΔE2000 4.59, and intensity Pearson r=0.628. These results establish parametric lights as a measurable editable-scene target and expose remaining bottlenecks in relation structure, light recall/intensity, and cross-engine generalization.

  - 现有单图像3D方法主要局限在房间尺度几何、烘焙光照或文本驱动生成，缺乏对**游戏规模场景**（密集前景、混合室内外、大量局部光源）的支持。

## 2. 论文提出的方法论

### 核心思想
- **引擎原生结构化解析**：将场景分解为可编辑实体（物体框+标签、参数化光源元组、网格、HDR环境图），通过结构化token序列生成，而非隐式场或自由生成。
- **分治策略**：框和光源分别由独立VLM解析（避免联合训练信号淹没），逐物体重建网格，HDR估计补充全局光照，最后用智能体只做**受限编辑**（不替换结构化解析）。

### 关键技术细节
1. **Lumera-2K数据集**：
   - 从2,513个UE5项目提取：373万组件、6300万物体实例、10.26万参数化光源、9.51万相机视图。
   - **场景感知相机规划**：通过前景聚类、室内房间分割、多模式候选采样、壁遮挡测试、贪婪多样性选择，将每个项目扩展到16-100个有效视图。
   - **标签提取**：VLM基于孤立物体渲染图+弱资产名提示生成开放词汇标签。
   - **光源标注**：提取点光、聚光、定向光、矩形光、天光的原生属性（位置、方向、强度、颜色、角度等），监督目标简化为7维元组 (x,y,z,r,g,b,I)。

2. **Lumera-Box：3D框解析**
   - 基于SpatialLM-1.1-Qwen-0.5B微调，输入彩色点云，输出序列化的定向3D框：`Bbox(class, x, y, z, yaw, sx, sy, sz)`。
   - 适应游戏领域：抑制wall/floor/terrain等标签、多视图同一项目监督、类平衡。
   - 训练目标：自回归交叉熵损失（公式5）。

3. **Lumera-Light：参数化光源解析**
   - 使用相同架构但**独立微调**，输入点云，输出光源元组：`Light(x, y, z, r, g, b, I)`。
   - 理由：框密度远大于光源，联合训练会淹没稀疏光源信号；独立检查点可分别改进。

4. **网格恢复与环境光**
   - Depth Anything 3提供深度、相机、点云。
   - 将预测框投影到图像获得矩形提示，SAM3D从alpha抠图重建带纹理网格，通过变换矩阵T_i放置回场景。
   - IntrinsicHDR从图像估计HDR全景或SkyLight，补充全局照明。

5. **分阶段智能体优化**
   - 采用VIGA分析合成循环，但加入**阶段感知硬作用域**：
     - **几何阶段**：只允许编辑物体偏航角和尺度，位置冻结。
     - **光照阶段**：只允许编辑已有光源参数、环境强度、曝光。
   - 执行器进行静态检查（代码范围）、结构场景差异检查、阶段前置条件检查，违规则回滚并将违规信息写入验证器报告。

## 7. 优点

- **任务创新**：首次将引擎原生参数化光源作为可编辑场景重建的目标实体，填补了现有方法忽略可编辑性的空白。
- **大规模高质量数据集**：Lumera-2K提供6300万物体、10.26万光源，覆盖室内外、密集游戏场景，远超现有数据集规模。
- **结构化输出设计**：框和光源都以序列化token形式预测，直接对应游戏引擎实体，无需后处理。
- **分阶段智能体优化**：硬作用域设计避免了VLM在编辑时混淆几何和光照，保证可控性。
- **全面基准指标**：框解析涵盖12项指标，光源解析涵盖14项，包括感知指标（ΔE2000）和结构一致性，评价体系完整。
- **开放性与可复现**：项目页面提供代码和数据集，方法基于公开SpatialLM微调，便于复现。

## 8. 不足与局限

- **框精度未饱和**：mAP仅0.1141，严格重叠率低，长尾分布和对称物体（如方形物体偏航角歧义）是主因。
- **关系结构薄弱**：SRF和锚点召回率大幅落后WildDet3D，序列化预测缺乏显式关系建模。

- **大场景几何漂移**：室外分割Chamfer-L2约17米，前端深度估计和坐标校准有瓶颈。
- **单引擎局限**：仅基于UE5，未验证Unity/Godot等引擎泛化性。
- **智能体优化仅案例验证**：缺乏大规模定量评估，也未与无优化基线在全部测试集上对比。
- **资源信息缺失**：未报告训练GPU型号、数量、耗时，经济性不可评估。
- **少量消融**：仅对比一个先前检查点和单个光照案例，消融覆盖不足。
