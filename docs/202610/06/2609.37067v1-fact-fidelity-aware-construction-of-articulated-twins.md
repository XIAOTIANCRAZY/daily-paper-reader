## 摘要
视觉上逼真的铰接资产在接触交互中仍可能失败，或表现出不准确的运动。我们提出 FACT（保真度感知的铰接孪生构建），这是一个智能体框架，可逐步构建铰接孪生，以提升几何、接触和动力学保真度。该智能体在共享的可编辑表示上驱动“证据—诊断—修正”循环，利用定量反馈选择测量与模型编辑，同时由数值工具执行并验证更新。它通过特征规划、针对性测量和诊断细化，从图像中重建可编辑的铰接几何。基于该参考，它在保真度约束压缩之前，通过任务感知的局部重新划分来修复碰撞代理。最后，它从被动响应视频中构建响应模型，利用仿真残差指导模型修正和约束物理参数拟合。实验表明，FACT 相比基线提升了几何重建，能够以更简单的碰撞代理实现更可靠的交互，并且比直接参数推断更好地复现留出的物理响应。

## Abstract
Visually plausible articulated assets may still fail during contact interactions or exhibit inaccurate motion. We present FACT (Fidelity-Aware Construction of Articulated Twins), an agentic framework that progressively constructs articulated twins to improve geometry, contact, and dynamic fidelity. The agent drives an evidence--diagnosis--revision loop on a shared editable representation, selecting measurements and model edits using quantitative feedback, while numerical tools execute and validate the updates. It reconstructs editable articulated geometry from images through feature planning, targeted measurements, and diagnostic refinement. On this reference, it repairs collision proxies through task-aware local repartitioning before fidelity-constrained compression. Finally, it constructs response models from passive-response videos, using simulation residuals to guide model revision and constrained physical parameter fitting. Experiments show that FACT improves geometric reconstruction over baselines, enables more reliable interaction with simpler collision proxies, and better reproduces held-out physical responses than direct parameter inference.

## 1. 核心问题与研究动机

- **背景**：仿真让具身智能体通过反复交互获得经验，仿真平台、铰接资产库与程序化生成的发展扩大了这一机会；生成式与智能体系统也让"从视觉输入创建资产"变得更容易。
- **核心矛盾**：**视觉上逼真 ≠ 可交互**。仅增加"看起来合理"的铰接资产数量，并不能带来更忠实的交互体验。资产同时决定了机器人"看到什么"和"动作后发生什么"：接触在哪里建立、哪些运动可行、物体运动如何随时间演化。
- **具体失效模式**：
  - 图像重建（如 Articraft）可能错估抽屉深度、把手间隙、内部空腔，产出"看着像但无法完成目标交互"的资产；
  - 碰撞近似（如 EmbodiedGen V2 使用 CoACD 生成凸碰撞代理）可能填满把手开口、阻塞抽屉行程；
  - 接触可行 ≠ 运动响应忠实：Articraft 用语言模型先验给出质量/阻尼，而实例级响应需针对观测轨迹标定。
- **三类互补保真度**（论文的核心分解）：
  1. **几何保真**：结构与尺寸；
  2. **接触保真**：任务相关的交互与运动可行性；
  3. **动力学保真**：运动响应。
- **核心洞察**：应当在一个**共享可编辑表示**上逐步接地（grounding）——几何与关节指导碰撞细化，二者共同构成动力学标定的固定基准；而"该测什么、该改什么"取决于具体部件与具体失败模式（窄开口与错误关节响应需要不同证据）。

## 2. 方法论

### 2.1 核心思想

- 将铰接孪生表示为 **A = (G, K, C, θ)**：部件几何、运动学图、碰撞代理、物理参数。
- 智能体在共享可编辑表示上驱动 **"证据—诊断—修正"（evidence–diagnosis–revision）循环**：智能体用语义理解 + 定量反馈选择测量与模型编辑，数值工具负责执行并验证更新。
- 建立三类映射：几何差异 → 可编辑特征；自由空间/运动违例 → 碰撞划分；轨迹残差 → 响应模型与物理参数。
- 阶段化流水线：先固定几何与关节 → 细化碰撞 → 最后固定 (G, K, C) 做动力学标定；共享部件身份与 body frame 保持跨阶段对应。

### 2.2 几何保真：特征规划—测量—细化（Sec. 3.2）

- **特征规划**：智能体检视整物体与孤立部件视图，识别逻辑部件与结构需求；特征计划规定特征类型、关系、待测参数、与源区域的链接。每个部件可组合拉伸、扫掠、壳体、减材特征；特征与必须保留的可见结构（开口、接触、重复元素）绑定。规划只决定"表示什么、测什么"。
- **特征条件测量**：对每个参数，智能体选择源区域、坐标系、测量流程，几何工具计算数值。投影轮廓与轴向范围约束拉伸剖面与深度；截面中心与接触区域约束把手的路径与端点；测量轮廓被约简为可编辑剖面控制点；依赖参数通过对称性、重复性、接触关系推导。最终实现为可执行程序 **P(φ)**，由可编辑特征生成重建网格 **Ĝ**（而非复制源三角面片）。
- **诊断细化**：用双向表面距离、匹配视角轮廓、并排渲染比较 Ĝ 与 M；部件级诊断借助源对应关系定位误差。错误归因：
  - 特征表示不足 → 重新规划（replan）；
  - 尺寸/位置错误 → 重新测量（remeasure）；
  - 实现错误 → 修正程序（correct code）。
  - 只有同时通过自动几何校验与智能体视觉检查才接受。
- **功能补全与关节**：单独一遍添加/细化最小功能结构（空腔、支撑、安装座），用类别知识引导未观测结构；一起运动的部件分组成刚体；每个关节指定父子 body、类型、轴、原点、运动限位；采样位姿（含行程端点）暴露干涉并触发几何或关节位置修正。
- **校验阈值**（附录 B.1）：每轴尺寸误差 < 5%，中心误差 < 0.02·D_M，双向全局 P95 表面距离 < 0.02·D_M，规范视角轮廓 IoU ≥ 0.90。

### 2.3 接触保真：任务感知碰撞细化（Sec. 3.3）

- **表示与初始化**：每个刚体 b 的碰撞代理为凸包并集 **C_b = ∪ C_{b,h}**；CoACD 作为后端；默认区域分解 **C₀** 初始化，并设定总凸包预算 **H_max = H(C₀)**。参考几何 G 与关节 K 保持固定。
- **任务感知诊断**：智能体识别可能的交互，选取接触区域、接近空间、运动间隙进行评估。任务自由空间定义在"各姿态下所有参考刚体几何并集之外"，**独立于候选代理**。评估指标包括逐体体积重叠、缺失/多余体积、任务区域占用、参考确认无碰撞位姿处的虚假体间碰撞；运动检查采样全程（含端点），在失败附近加密采样，并定位责任凸包对与源区域。
- **诊断式划分修正**：智能体选择局部编辑——重新划分或分裂区域、调整区域分解参数、合并体内兼容区域/凸包。示例：把把手拆为侧支撑与桥接，避免凸包填满开口。编辑后重新生成受影响代理并整体重评估；寻找满足凸包预算、通过运动检查、且体积/自由空间误差相对 C₀ 有界的代理，固定为质量参考 **C_a**。
- **可行性优先压缩**：从 C_a 出发搜索更简单代理，**优先最小化凸包数 H 再最小化顶点数 V**：
  - `lexmin_C (H(C), V(C))`
  - 约束：`C ∈ F(G,K)`（全运动空间无自碰撞）、`H(C) ≤ H_max`、`e(C) ⪯ e(C_a) + δ`；
  - 误差向量 e 收集逐体 1−IoU、缺失与多余体积比、各
