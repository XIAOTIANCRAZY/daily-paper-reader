## 摘要
组合式3D场景重建近期主要从两个方向进行探索：一是智能体推理，它能提供对空间关系的语义理解，但与输入图像缺乏精确对齐；二是视觉几何基础模型，它能从输入图像预测稠密点图，但重建质量有限。因此，从单张单目图像中恢复出具有准确物体间关系和高保真重建质量的完整3D场景仍然具有挑战性。本文提出了HARMONY，一种分层思维链框架，同时利用智能体推理和视觉几何基础。给定一张室内场景图像，从空白的3D平面图出发，HARMONY首先以参考图像校准相机，建立具有语义基础的空间坐标系，然后利用智能体VLM推理恢复3D房间布局和初始摆放顺序。接着，它按分层顺序摆放物体，从壁挂式元素、独立式家具，到家具上方的依附装饰物。我们还对家具采用深度优先遍历，使每次摆放都以先前已解析的结构为条件，并采用反思式反馈回路以避免误差累积。在VLM完成每个物体摆放后，我们利用点云估计进行基于几何的细化，使渲染图像与输入更好地对齐。HARMONY能够生成与参考图像语义一致且感知对齐的3D场景，将单图像组合式重建扩展到复杂室内场景图像。在合成和真实图像上的实验表明，HARMONY优于所评估的重建基线，而与GPT-6 Astra的定性比较表明，其物体排列更忠实，场景细节保持得更好。

## Abstract
Compositional 3D scene reconstruction has recently been explored from two directions: agentic reasoning that provides semantic understanding of spatial relationships but lacks precise alignment with input images; and visual geometry foundation models that predict dense point maps from input images but the reconstruction quality is limited. Therefore, recovering a complete 3D scene from a single monocular image with accurate inter-object relationships and high-fidelity reconstruction quality remains challenging. In this paper, we present HARMONY, a hierarchical chain-of-thought framework that leverages both agentic reasoning and visual geometry foundation. Given an image of an indoor scene, starting from an empty 3D floorplan, HARMONY first calibrates the camera against the reference image to establish a semantically-grounded spatial frame, then uses agentic VLM reasoning to recover the 3D room layout and an initial placement order. It then places the objects in a hierarchical order, from wall-mounted elements, free-standing furniture, to dependent decorations on top of furniture. We also use depth-first traversal for furniture so each placement conditions on previously resolved structure and a reflective feedback loop to avoid error accumulation. After each object placement by VLM, we use the point cloud estimations to perform geometry-based refinement so that the rendered image aligns better with the input. HARMONY can produce 3D scenes that are semantically consistent and perceptually aligned with the reference image, extending single-image compositional reconstruction to complex indoor scene images. Experiments on synthetic and real-world images demonstrate that HARMONY outperforms the evaluated reconstruction baselines, while qualitative comparisons with GPT-6 Astra suggest more faithful object arrangements and better preservation of scene details.

## 2. 方法论

### 2.1 核心思想
- 以分层链式思维（Hierarchical Chain-of-Thought）为核心骨架，让VLM负责语义与空间关系推理（“谁靠着什么、坐在什么上、朝向什么、与什么配对”），让视觉几何基础模型负责精确的度量定位（轮廓+深度），两者分工协作。
- 从空房间出发，先标定相机建立语义锚定的空间坐标系，再按层级顺序摆放物体，每阶段后设反思反馈回路防止误差累积。

### 2.2 关键技术细节与流程

- **3.1 房间布局与相机初始化**
  - *VLM语义初始化*：VLM从语义线索推断房间尺寸先验（如卧室约3×4×3 m），识别最深可见墙角作为空间锚点，并标注各可见墙面（左/后/右），形成语义对齐的空房间盒。
  - *VGGT几何细化*：对VGGT预测的点云做SVD法向聚类，估计曼哈顿框架（宽、竖直、深三正交轴）；用逐轴直方图拟合定位六个包围平面，识别最深地板角点 X_f 及其天花板对应点 X_c。
  - *相机标定*：闭式求解单一相似变换（旋转 R_align、均匀缩放 s、平移 t）：
    - 旋转：按相机前向对齐分配宽/深轴，修正符号使行列式为+1；
    - 缩放：s = H_room / ‖X_c − X_f‖，以房间高度为唯一度量参考；
    - 平移：t = cX_f − sR_align X_f，把地板锚点钉到规范墙角；
    - 相机位姿：R = R_0 R_align^T，c = sR_align c_0 + t。

- **3.2 物体分割与重建**
  - 按层级（壁挂、独立家具/天花板、装饰物）检测分割，VLM列出物体清单，经开放词汇检测（LocateAnything）与SAM2分割，去重过滤后把装饰物关联到支撑家具。
  - VLM生成带场景上下文的描述，用图像编辑模型（Gemini）做遮挡区域修补（amodal completion），并自检一致性。
  - 用Hunyuan3D-2生成网格；对非规范位姿的网格做PCA主轴对齐，再由VLM通过多视角渲染标注正面朝向，建立各物体的规范坐标系。

- **3.3 分层场景重建**
  - *放置顺序推理*：以最深墙角为参照做深度优先遍历——先沿两相邻墙放置靠近锚点的物体，逐步向外推至靠近相机的物体，保证每次摆放时新物体无遮挡、可基于已确定结构推理。
  - *VLM放置*：VLM从先验给定初始尺寸，推理空间关系提示（如“沙发背靠左墙”“花瓶在桌上”“椅子朝向小茶几”），用规范正面设定朝向，再通过视觉对比做小幅旋转调整；对装饰物做支撑家具一致性校验（包围盒重叠最大者）。
  - *几何细化（两阶段耦合）*：
    - 图像空间轮廓：对齐渲染轮廓中心 u_c 与分割掩码中心 û_c，横向平移 p ← p + Δu·Z/f_x·r̂；由表观角尺寸 α = ŵ/f_x = s·w_obj/Z 得到尺度-深度比 s/Z；
    - 深度空间：用VGGT点云经掩码分割，提取参考与渲染的前表面稳健均值 c_front，按视线方向修正深度 Z′ = Z + (c_ref − c_ren)·f̂，最终度量尺度 s = ŵ·Z′/(f_x·w_obj)。
  - *碰撞消解*：对碰撞对计算各自最小无碰撞位移 δ_i、δ_j，取较小者移动对应物体；若无法分离则联动邻域，仍冲突则调用VLM修正放置顺序从源头解决。
  - *反思反馈回路*：每阶段后渲染当前场景回传VLM，检查尺度、朝向、错位等问题并纠正，同时对成组物体（如配对椅子）统一尺度，装饰阶段后清点补缺。

- **3.4 光照与材质**
  - VLM依据类别先验为每个物体估计PBR材质（粗糙度、金属度、IOR、透射等）与物理属性（重量、厚度、弹性）。
  - VLM识别发光源（灯具、窗户），估计激活状态、颜色、强度；用Blender Cycles渲染与参考对比的反思回路迭代精修。
