## 摘要
赋予人工代理空间智能，需要对动态三维世界具备全面的生成式先验。我们提出世界运动模型（WMMs），通过稀疏的SE(3)位姿轨迹来捕捉“随时间变化的过去、现在与未来在何处发生什么”。WMMs基于这样一个观察：动态场景中的元素可以被一组刚性SE(3)轨迹很好地近似，这是用于4D建模的一种最小却富有表现力的基元。该表示将铰接物体、人体、手-物交互、分段刚性的场景动态、相机运动，乃至机器人状态和动作统一到一个共享空间中。基于这种表示，我们将这些实体的联合分布建模为一个灵活的序列建模问题，利用带有逐token噪声水平的流匹配。结合用于非序列条件化的上下文token机制，该公式支持在任意数量的实体和时间步之间进行任意到任意的边缘条件化。未来预测、运动补全、模型预测控制、逆运动学、跨具身重定向和策略学习等任务，都归结为在同一网络上应用不同的掩码。在3D视觉和机器人学的6个不同应用上的实验表明，WMMs具有多功能性和灵活性，并取得了强劲性能。

## Abstract
Equipping artificial agents with spatial intelligence requires a comprehensive generative prior over the dynamic 3D world. We propose World Motion Models (WMMs) that capture "what was, is, and will be where across time" via sparse SE(3) pose trajectories. WMMs are built on the observation that elements of dynamic scenes can be well approximated by a set of rigid SE(3) trajectories, a minimal yet expressive primitive for 4D modeling. This representation unifies articulated objects, human bodies, hand-object interactions, piecewise-rigid scene dynamics, camera motion, and even robot states and actions into a single shared space. Given this representation, we cast the joint distribution of these entities as a flexible sequence modeling problem, utilizing flow-matching with per-token noise levels. Coupled with a context token mechanism for non-sequential conditioning, this formulation supports any-to-any marginal conditioning across an arbitrary number of entities and time steps. Tasks such as future prediction, motion infilling, model-predictive control, inverse kinematics, cross-embodiment retargeting, and policy learning all reduce to the application of different masks over the same network. Experiments on 6 diverse applications of 3D vision and robotics demonstrate the versatility and flexibility of WMMs with strong performance.

  - 分段刚性方法（SE(3) 变换）虽物理基础扎实，但受限于**单智能体或固定物体**场景。
- **核心洞见**：真实场景运动是**低秩**的——复杂密集形变可由少量刚性本征轨迹的局部组合近似。因此可用**稀疏 SE(3) 位姿轨迹**作为统一、紧凑、物理可解释的 4D 建模基元。
- **整体含义**：该表示统一了铰接物体、人体、手物交互、分段刚性场景动态、相机运动以及机器人状态与动作，将"过去、现在、未来在何处发生什么"转化为一个统一的序列建模问题，为跨任务、跨本体的世界模型提供了共享抽象。

## 2. 方法论

### 2.1 核心思想
将动态 3D 世界表示为**稀疏 SE(3) 位姿轨迹集合**，把多实体、多时刻的联合分布建模为**带逐 token 噪声水平的流匹配（flow matching）序列问题**，从而用单一网络支持任意"已知-未知"划分的条件生成。

### 2.2 表示：运动的"语言"
- **Token 定义**：每个基本单元是 (T^(l)_i, F_i)，即一个位姿 T ∈ SE(3) 加一个跨时间共享的特征 F。
- **位姿参数化**（9 维，便于归一化）：
  T ≡ (x, x + δ·r₁, x + δ·r₂) ∈ R⁹，其中 x 为位置，r₁、r₂ 为旋转矩阵前两列（6D 旋转参数化），δ 为固定缩放（如 0.2）。
- **特征组成**：F_i = [f_sem; f_geo]
  - f_sem：DINO 像素特征（视频提示）或可学习嵌入（粗粒度语义类别）
  - f_geo：PointNet 从局部点云提取的几何描述子
- **轨迹与场景**：实体 i 的轨迹 τ_i = ([T^(l)_i, T^(m)_i, …]; F_i)，场景 X = {τ_i, τ_j, …} = (T, F)。
- **上下文 token**：在因果时间窗之外扩展一段**虚拟时间步前缀**，配独立可学习位置编码，用于非因果锚点（如 MPC 的远景目标、跨本体示例帧），训练与推理时与真实 token 同等对待。

### 2.3 建模目标
学习任意边缘条件分布族：
P(T_unk | T_obs, F, A)，∀ T_obs ⊂ T，T_unk = T \ T_obs
即对轨迹集进行"观测子集 vs 补集"划分所诱导的一切分布。这被作者视为"世界模型"的操作性定义。

### 2.4 训练：逐 token 噪声水平的流匹配
- **前向过程**：对每个 token 独立采样噪声水平 λ_{i,l} ~ U[0,1] 与高斯噪声 ϵ_{i,l} ~ N(0,I₉)：
  T^(l)_{i,λ} = (1 − λ_{i,l})·T^(l)_i + λ_{i,l}·ϵ_{i,l}
- **速度目标**：v*_{i,l} = ϵ_{i,l} − T^(l)_i
- **损失**（逐 token 误差求和）：
  L(θ) = E_{T,Λ,ϵ} Σ_{i,l} ‖M_θ(T_Λ, F, A, Λ)_{i,l} − v*_{i,l}‖²₂
- **为何单一目标足够**：随机 Λ 把 token 分成"近干净（观测类）"与"近噪声（目标类）"，覆盖所有条件反向过程；确定性划分只是极限情形。训练时还可按部署模式偏置噪声调度（如历史小 λ、未来大 λ）。

### 2.5 推理：同一网络上的不同掩码
推理时用户指定观测/目标掩码，观测 token 置 λ=0，目标 token 置 λ=1，将 M_θ 从 λ=1 积分到 0，得到 P(T_unk | T_obs, F, A) 的采样。典型掩码：
- **(i) 未来预测与策略**：过去 λ=0、未来 λ=1；仅状态实体为未来预测，含动作实体则为机器人策略。
- **(ii) 动作条件预测模型（前向动力学）**：动作已知、未来状态未知，用于 MPC 的可学习前向模拟器。
- **(iii) 运动规划与补全**：稀疏关键帧已知，其余为目标。
- **(iv) 重定向、伙伴预测、逆动力学**：按实体划分；已知一方身体 → 跨本体重定向；已知手 → 手物伙伴预测；已知状态 → 逆动力学。
- **鲁棒性**：对真实观测把 λ 设为小正值（如 0.05）而非 0，使其成为"强提示"，积分中可轻微修正。
- **超出训练规模**：结合 RoPE 与逐 token 噪声，配合锚定滑窗采样器（Alg. 1）可生成远超训练实体数/时间步的密集轨迹。

### 2.6 架构实现
- **逐 token 条件（AdaLN）**：将 λ_{i,l} 的正弦嵌入、特征 F、辅助条件 A 的池化嵌入拼接，经宽 FFN 映射为每块 AdaLN 的 scale/shift 参数。
- **寄存器 + 分解注意力**：在 M×N token 网格上填充三块可学习寄存器，施加 5 种注意力：a（全局自注意力）、t/p（时间轴/实体轴自注意力）、s/q（同轴仅寄存器，通道加宽以低成本增表达）。
- **缺失观测训练**：无效时间步仍需参与注意力（推理时缺失掩码未知），故将无效 token 固定 λ=1（纯噪声），损失仅对含真值标签的 token 求和；虚拟上下文 token 用 1-bit 前缀掩码标记；文本/图像 token 作为注意力前缀。

- **实验组数**：覆盖 **6 类应用**（策略、场景预测、HOI、重定向、机械臂规划、手物交互），跨 5+ 数据集，外加多组消融：
  - Language Table：AdaLN 消融、逐 token 噪声消融、特征消融（F_sem / F_geo）
  - TraceGen：寄存器池、plain DiT 架构消融、语义特征消融
  - 重定向：旋转缩放 δ 消融（0.2 / 0.6 / 1.0）
  - 参数一致性：SMPL 与 G1 的原始 SE(3) vs 投影拟合误差
- **充分性**：
  - 在多个主流 benchmark 上取得 SOTA 或可比性能，且覆盖"策略—预测—规划—重定向"全链路，覆盖面广。
  - 消融设计有针对性，能说明各组件（AdaLN、逐 token 噪声、轴分解注意力、寄存器）的贡献（如去掉逐 token 噪声导致 0 成功率）。
  - 使用公开 benchmark 与官方协议（LAPA/LCB、CHOIS、TraceGen），对比方法齐全，**客观性与公平性较好**。
- **潜在不足**：每个 benchmark 单独训练一个 checkpoint，**未做跨域联合训练**（作者明确留作未来工作）；部分任务（如机械臂规划、TACO）以定性结果为主。

## 6. 主要结论与发现

- WMM 在策略学习（Language Table 宏平均 **87.2%**，超 LCB 80.0）、场景未来预测（TraceGen 全指标最优）、人-物交互（OMOMO 多项指标领先，且避免人体穿物）、人形重定向（FPS 86.97，SR-seq 0.869，超 GMR 与 PHUMA）上均达 SOTA。
- **单一网络**通过改变掩码即可在策略、动作先验、世界模型之间无缝切换。
- MPC 模式相比纯策略在 B2B/B2AL 上成功率更高、步数更少。
- TraceGen 中 P=128（训练仅见 128 条轨迹）反而优于 P=400，说明随机采样有防过拟合效果；跨域联合训练可行。
- 人形重定向中，WMM 兼具 GMR 的速度与 PHUMA 的物理合理性。

## 7. 优点

- **统一表示**：以稀疏 SE(3) 轨迹为共享语言，打破行为主体类别的壁垒，最小却富有表达力。
- **灵活条件化**：逐 token 噪声 + 上下文 token，支持任意实体 × 任意时间步的 any-to-any 条件生成，一套权重覆盖预测、策略、规划、逆动力学、重定向等多种任务。
- **架构高效**：寄存器 + 五类分解注意力，在 12K+ token 网格上保持可扩展性；逐 token AdaLN 实现精细条件控制。
- **鲁棒性设计**：观测噪声用 λ=0.05 软处理；缺失观测在训练中以纯噪声固定并屏蔽损失；锚定滑窗采样器支持超训练规模生成。
- **物理可解释**：直接输出刚体位姿，可与 SMPL、URDF 等参数化模型互转，且一致性误差小（骨骼长度 7.21mm、方向 2.99°）。

## 8. 不足与局限

- **每 benchmark 单独训练**：未实现跨域统一模型，联合训练与更多监督数据留作未来工作。
- **表示受限**：仅建模 SE(3) 刚性运动，未覆盖缩放、剪切等一般线性局部运动。
- **输入依赖几何**：需要深度与当前/过去状态估计，尚不能直接从 RGB 视频推理。
- **形态泛化有限**：对训练中未见过的新形态不能泛化；上下文机制能否解决有待进一步研究。
- **实验覆盖**：部分应用（机械臂多臂规划、TACO 手物）以定性展示为主，缺乏统一定量基准；未报告训练时长/总算力，复现成本不透明。
- **偏差风险**：依赖重建/跟踪工具产生的 SE(3) 标签质量（如 4D 重建、Procrustes 拟合），数据生成误差可能传导至模型。
- **应用限制**：对控制器固定（PD 增益等）的假设使动作可退化为虚拟目标位姿，控制器变化时需重新适配。
