## 摘要
具身智能体受益于兼具对真实世界观测的视觉保真度与物理交互性的3D环境。现有的单图像桌面重建方法能够恢复合理的场景几何，但通常将物体表示为整体式刚体，将交互限制为整物体刚性运动，无法实现可执行的部件级铰接。与此同时，恢复与输入视角一致的场景布局仍然具有挑战性，因为单一观测可能对应多种合理的位姿-尺度配置。我们提出ArticuTable，一个单图像3D桌面重建框架，可同时恢复可执行的部件级铰接和与输入视角一致的场景布局。在物体建模方面，我们引入生成鲁棒的铰接建模（GRAM），它将由多模态大语言模型引导的关节拟合与语义状态推理相结合，从不完美的整体式代理网格中恢复可靠的关节参数和有效的运动范围，从而将其转换为可执行的铰接资产。在场景布局方面，我们引入渐进式语义-几何场景配准（PSGSR），它在互补的度量、平面和输入视角约束下逐步缩小位姿-尺度搜索空间，并通过结构感知的语义对应关系解决朝向歧义，从而生成与输入视角一致的场景布局。我们进一步贡献了ArticuTable-100，一个精选的100个可直接用于仿真的桌面场景集合。包括用户研究在内的大量评估表明，其在视觉保真度、输入视角一致性、铰接质量、物理合理性和仿真就绪度方面均表现出色。

## Abstract
Embodied agents benefit from 3D environments that combine visual fidelity to real-world observations with physical interactivity. Existing single-image tabletop reconstruction methods recover plausible scene geometry but typically represent objects as monolithic rigid bodies, limiting interaction to whole-object rigid motion and precluding executable part-level articulation. Meanwhile, recovering a scene layout consistent with the input view remains challenging because a single observation may admit multiple plausible pose-scale configurations. We present ArticuTable, a single-image 3D tabletop reconstruction framework that recovers both executable part-level articulation and an input-view-consistent scene layout. For object modeling, we introduce generation-robust articulation modeling (GRAM), which combines joint fitting guided by a multimodal large language model with semantic state reasoning to recover reliable joint parameters and valid motion ranges from imperfect monolithic proxy meshes, thereby converting them into executable articulated assets. For scene layout, we introduce progressive semantic-geometric scene registration (PSGSR), which progressively narrows the pose-scale search space under complementary metric, planar, and input-view constraints and resolves orientation ambiguity through structure-aware semantic correspondences, yielding a scene layout consistent with the input view. We further contribute ArticuTable-100, a curated collection of 100 simulation-ready tabletop scenes. Extensive evaluation, including a user study, demonstrates strong performance across visual fidelity, input-view consistency, articulation quality, physical plausibility, and simulation readiness.

- **解耦实例发现与语义识别**：使用类别无关分割器在前视图与合成俯视图分别提取匿名实例提案，通过**表格归一化水平范围、相对空间位置、掩码面积**进行一对一几何匹配（匈牙利算法），避免因类别缺失而漏检物体。
- 由 MLLM 识别可重建实例、分配语义身份与可操作性类型，估计尺寸、放置与支撑关系；对每个实例生成条件图像，用 TRELLIS.2 重建独立代理网格并统一到重力对齐坐标系。

### 2.3 GRAM（生成鲁棒的铰接建模）
- **分割与运动学结构推断**：用 P3-SAM 将网格划分为几何基元，MLLM 结合外观与基元结构证据，将共动基元分组为功能连杆，推断父子关系与关节类型（hinge / spin / prismatic），构建有根运动学树。
- **MLLM 引导的关节拟合**：
  - 通过尺度自适应接触阈值定义父子连杆接触区域 \(C_{p,c}\)（式2）。
  - 几何方法生成关节类型特定假设（revolute 由接触分布得轴与枢轴；prismatic 由子连杆主方向得轴候选）。
  - **不直接接受局部估计**，而是由 MLLM 结合全局多模态与结构证据选择/修正轴方向与枢轴位置。
- **语义状态推理**：
  - 将**观测关节状态**与**物体固有运动范围**分离建模：先在规范坐标系估计观测坐标 \(q^{obs}_j\)，revolute 用几何闭合推理恢复规范零位，prismatic 沿外向轴估计位移。
  - 结合功能语义与几何可行性证据推断固有区间 \(Q^{int}_j=[0,q^{max}_j]\)（式3），将几何视为可行性证据而非唯一依据，降低对网格伪影的敏感性。
- **URDF 导出**：烘焙语义零位变换，转换到 Z-up URDF 坐标系，写出 GLB 视觉网格 + OBJ 碰撞网格，按固定材料密度计算质量与惯量，并校验 XML 与网格路径。

### 2.4 PSGSR（渐进式语义-几何场景配准）
- **渐进式多约束配准（PMCR）**：
  - 先以支撑桌建立共享度量场景坐标系（VGGT 点云拟合平面 + 表宽估计尺度 \(s_0\)，式11）。
  - 三阶段递进：**点云对齐**（trimmed 最近表面距离，式13-14，仅优化平面平移、偏航、均匀尺度）→ **俯视图配准**（优化平面位置、足印尺度、偏航）→ **输入视角配准**（优化平面位置、各向异性尺度、偏航、轮廓与竖直放置），每阶段由前一阶段初始化。
  - **支撑感知垂直放置**：从桌子向上遍历支撑层级，物体由父物体支撑时设置初始高度，并在输入视角优化中优化竖直残差 \(\eta_i\)，用接触可行区间 \(Z_i\) 投影（式16-17）避免悬空与穿插。
- **结构感知语义位姿选择（SASPS）**：
  - 掩码引导初始化解决位置与尺度，但偏航仍有歧义；SASPS 对偏航候选进行排序：俯视图用 2D 旋转，输入视角用残差对称位姿的 3D 渲染。
  - 用冻结的 DINOv2 提取 patch 特征，构建双向最近邻对应集，并计算**结构感知权重** \(w^k_{ab} = \alpha^{ref}_a \beta^k_b s^k_{ab}\)（式4，分别度量参考外观结构、候选法线图几何结构、DINO 语义匹配置信度）。
  - 以加权位移损失 \(L_{dir}\)（式5）选择最优偏航假设，初始化可微细化（掩码投影目标 = IoU + 边界感知 SDF 惩罚，式18）。

### 2.5 ArticuTable-100
- 人工精选的 100 个仿真就绪桌面场景，每个以自包含 USDZ 包分发，含带纹理视觉资产、碰撞几何、可执行铰接模型，可直接在 Isaac Sim 加载。

## 3. 实验设计

### 3.1 数据集 / 场景与 Benchmark
- **场景级评估**：150 张由图像生成模型产生的桌面参考图像（非配对 GT 3D 渲染），每个方法使用相同单目输入，并从对应输入视角渲染重建场景。
- **铰接评估**：Lightwheel 基准全部 243 个资产，遵循官方协议，覆盖部件分解、铰接几何与关节估计。
- **人工审计**：完整 150 场景评估集，覆盖 425 个候选资产与 527 个预测关节。
- **用户研究**：59 名参与者，每人评估 10 个场景，对 5 个匿名方法输出排名，共 590 个有效排名/方法。
- **仿真验证**：Isaac Sim + PhysX 中的场景编辑与物理交互。

### 3.2 对比方法
- 场景级：ACDC、Gen3DSR、MIDI、TabletopGen。
- 铰接：图像条件方法 SINGAPO、PAct、PhysX-Anything、URDF-Anything+；网格条件方法 Articulate AnyMesh、URDF-Anything+、Particulate（强基线）。
- 共享上游组件：TRELLIS.2 用于物体级3D生成，GPT-5 用于多模态推理。

### 3.3 评估指标
- 输入视角一致性：LPIPS ↓、DINOv2 ↑、CLIP ↑。
- GPT-5 评估：视觉保真 VF、图像对齐 IA、物理合理性 PP（1-7分）、总体排名 OR。
- 物理有效性：ColO（物体对相交比例）、ColS（含相交场景比例）。
- 铰接：部件匹配精度/召回、rest mIoU、Art. gIoU、OC、AE（角度误差）、LE（轴位置误差）。

## 4. 资源与算力

- 论文**未提及任何训练算力**（GPU 型号、数量、训练时长），因为 ArticuTable 使用**固定的预训练模型，无需任务特定训练或微调**。
- 仅报告了**推理运行时**：所有运行时间在单张 NVIDIA GeForce RTX 4090 上测量（排除排队时间）。
  - PSGSR 总耗时 141.4 ± 14.0 秒/场景，其中输入视角配准占约 73.1%（103.3 秒）。
  - 表格与相机初始化 8.3 秒，点云对齐 14.1 秒，俯视图配准 15.7 秒。
  - 位姿选择效率对比：完整 PSGSR 179.4 秒；仅前视 SASPS 批量渲染 374.8 秒（2.09×），顺序渲染 595.3 秒（3.32×）。

## 5. 实验数量与充分性

- **实验组数概览**：
  - 场景级重建与配准：150 张图像 × 4 个基线 + 本方法。
  - 铰接资产评估：243 个 Lightwheel 资产，7 个对比方法。
  - 人工审计：425 个候选资产、527 个关节，含 20% 二次复核（85 资产、101/102 项）。
  - 消融实验：
    - GRAM 组件消融（2×2 析因设计，MLLM 引导关节拟合 × 语义状态推理）。
    - PSGSR 消融（5 个变体：仅点云、无俯视图、仅俯视图、无 SASPS、完整模型）。
    - 位姿选择效率消融（完整 vs 仅前视 SASPS）。
  - 用户研究：59 人 × 10 场景 × 5 方法。
  - 仿真验证：场景编辑（移除/插入/重排）+ 物理交互（重力沉降、接触搬运、铰接开启）。
- **充分性与客观性**：
  - 实验维度较全面，覆盖视觉、物理、铰接、仿真与人类主观评价。
  - 基线控制较公平：共享上游组件（TRELLIS.2、GPT-5）被统一，检索类方法保留原机制，并明确说明"不改变各方法定义性的生成/检索范式"。
  - 人工审计提供**评分者间一致性分析**（资产级精确一致 83.5%，结构 κ=0.474，运动 κ=0.659），仅 1 个资产出现直接通过-失败分歧，增强了主观评估的可信度。
  - **潜在不足**：场景级评估使用生成图像而非配对 GT 3D，指标以图像相似度为主，局部朝向误差对 LPIPS/DINOv2/CLIP 影响有限，故补充了定性消融（图5）；这一点论文自己也承认。

## 6. 主要结论与发现

- **场景级**：ArticuTable 在所有场景级指标上领先，LPIPS 0.2398、DINOv2 0.8991、CLIP 0.9265 均为最优；ColO 仅 0.3819%、ColS 10.67%，显著低于各基线，说明**输入视角对齐与物理有效性可兼得**。
- **铰接**：GRAM 在 Lightwheel 上取得最强的部件匹配精度（91.15%）与最低角度误差（17.26°）和轴位置误差（0.034），在任务训练无关方法中优于 Articulate AnyMesh；在真实图像生成网格上比 Particulate 更稳健，避免不合理运动或退化状态。
- **消融**：
  - MLLM 引导关节拟合主要改善轴方向与位置（AE 降低 57.1%，LE 降低 20.9%）。
  - 语义状态推理改善跨运动状态的铰接几何（Art. PC 降 3.9%，OC 降 13.6%）。
  - PSGSR 中逐级细化持续提升，SASPS 启用后三项指标均最佳；仅前视 SASPS 视觉相当但计算代价高 2.09–3.32 倍。
- **用户研究**：85.59% 的评估将 ArticuTable 排在第一，Top-2 率 98.14%，平均排名 1.17，远优于最强基线 TabletopGen（平均 2.24）。
- **仿真验证**：实例级表示支持物体移除、插入、重排；重力沉降、工具箱搬运内部物体、盖子铰接开启等交互验证了碰撞几何与可执行铰接的可用性。

## 7. 优点

- **问题定位精准**：明确指出现有单图重建"整体刚体化"与"单视角位姿-尺度歧义"两大瓶颈，并给出针对性方案。
- **无需铰接专用训练**：GRAM 在不进行任何铰接特定训练或微调的情况下，从**不完美生成网格**中恢复可执行 URDF，工程实用性强。
- **鲁棒性设计巧妙**：
  - 将几何接触估计作为假设而非最终答案，用 MLLM 全局多模态证据修正；
  - 将几何视为"可行性证据"而非唯一依据，降低对网格伪影的敏感性。
- **渐进式配准思路清晰**：点云 → 俯视图 → 输入视角的逐级约束传播，有效缩小非凸搜索空间并缓解初始化敏感问题。
- **SASPS 的加权语义对应**：结合外观结构、几何结构、DINO 语义置信度的双向匹配，在低成本 2D 旋转下解决偏航歧义。
- **贡献数据集**：ArticuTable-100 为自包含 USDZ 包，含视觉网格、碰撞几何与可执行铰接，可直接在 Isaac Sim 使用，对下游具身操作研究有价值。
- **评估体系完整**：定量指标 + GPT-5 评估 + 人工审计（含评分者间一致性）+ 用户研究 + 物理仿真验证，多角度交叉验证。

## 8. 不足与局限

- **相机投影模型不匹配**：使用估计的针孔相机渲染，投影模型与参数可能与输入图像不完全一致；在强离轴视角下，图像边界附近残差更明显（图7中重建杯子投影倾斜度小于输入杯子）。
- **场景范围受限**：仅针对桌面场景，未验证更大规模或复杂室内场景的泛化能力。
- **依赖固定预训练模型**：GPT-5、SAM 3、TRELLIS.2、P3-SAM、VGGT、DINOv2 等均为固定组件，其能力上限与 API 成本可能制约实际部署。
- **人工审计中的不可判断样本**：425 个候选资产中有 7 个因视觉证据不足被排除，另有 11 个资产无预测关节（4 个计为失败、7 个不可判断），说明部分生成结果存在结构性缺失。
- **失败原因分布**：77 个非通过项中，运动范围错误（17）、部件分割错误（15）、轴/枢轴不合理（13）、拓扑或关节类型错误（12）、碰撞或脱离（10）、缺失铰接（10），表明 GRAM 在部件分割与拓扑推断上仍有提升空间。
- **场景级指标局限**：LPIPS/DINOv2/CLIP 主要衡量整体图像相似度，局部朝向误差影响有限，甚至错误朝向有时得分更高；论文通过定性消融部分弥补，但缺乏直接的几何精度指标。
- **用户研究样本特征偏斜**：72.9% 为 18–24 岁，81.4% 为男性，55.9% 无 CG/3D 视觉经验，可能影响偏好分布的代表性。
- **未报告训练算力**：由于无需训练，论文未提供训练资源信息，但也未讨论推理阶段的完整端到端成本（除 PSGSR 外）。
